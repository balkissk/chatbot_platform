FAQ

Common questions before rollout

Can I embed an assistant on my website?

Yes. Published assistants can be launched through the Web Widget for website embedding.

Can assistants answer using my own documents?

Yes. Knowledge Bases support trusted content that assistants can use for grounded responses.

Can I test an assistant before publishing?

Yes. You can use Test Flow, evaluations and readiness checks before release.

Does ChatBot Factory provide a REST API?

Yes. REST API publishing is available alongside Public Chat and Web Widget channels.

Can I evaluate and version assistants before release?

Yes. Versions and evaluations help validate assistant changes before publishing.
